# Examen 01

## 1. Clase
Una clase es una plantilla que define atributos y métodos para crear objetos.

## 2. Encapsulamiento
El encapsulamiento es el principio que protege los datos de una clase restringiendo el acceso directo mediante private y permitiendo acceso controlado con public.

## 3. Constructor
Un constructor es un método especial que se ejecuta automáticamente al crear un objeto y sirve para inicializar sus atributos.
